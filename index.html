V1 Tracker

Private laptop app

The public location dashboard has been removed from this page. To use the installable dashboard, open the laptop-dashboard/ folder from this repository through GitHub Pages, or run it on your laptop using a local HTTPS/localhost web server.

Sign in with your own Supabase account inside the dashboard. The backend must enforce account ownership before returning any location. A PWA can be installed on other devices too, so installation alone does not lock it to one laptop.

Keep your login and phone Secret Key private. Track only your own phone or a device whose owner has explicitly agreed.
