# V1 Tracker Android starter

Open the `android/` folder in Android Studio. Set up your Supabase project first (see the repository root README and `supabase/README.md`). The app lets the device owner sign in, enroll this phone for its own unique key, and explicitly start/stop visible location sharing. A persistent Android notification is shown while sharing.

You must enter your own Supabase project URL and anon/public key in the app. These are project configuration values, not the service-role key. Never put the service-role key in the app. This is a starter project and should be tested on a real Android device.
